Confidentialité & cookies

Version du 1er octobre 2026.

Cette déclaration explique le traitement de vos données lors de la consultation de pastamo.ch et de vos demandes à Pasta Mo.

Qui est responsable ?

Pasta Mo, entreprise individuelle exploitée par Younes Malik, Chemin des Sports 16, 1203 Genève, Suisse.

Pour toute question relative à vos données : ciao@pastamo.ch.

Lorsque vous consultez le site

Le site est hébergé par GitHub Pages. Votre navigateur transmet à l’hébergeur les données techniques nécessaires pour afficher les pages, notamment votre adresse IP. GitHub indique que GitHub Pages enregistre et conserve les adresses IP des visiteurs à des fins de sécurité. Informations de GitHub Pages

Lorsque vous nous contactez

Nous traitons les informations que vous nous communiquez : nom, adresse e-mail, contenu de votre message et détails de l’événement, tels que son type, sa date, son lieu et le nombre estimé de personnes. Elles servent à répondre à votre demande, préparer une proposition et, si vous retenez nos services, organiser et gérer la prestation.

Le formulaire prépare un message dans votre navigateur puis vous permet de l’ouvrir dans votre messagerie. Il ne transmet pas automatiquement son contenu à Pasta Mo. Nous recevons votre demande lorsque vous envoyez l’e-mail. Votre fournisseur de messagerie intervient également dans cet envoi.

Notre messagerie est fournie par Hostpoint SA, en Suisse. Hostpoint indique que ses serveurs et données de messagerie sont localisés en Suisse. Informations de Hostpoint

Prestataires et traitement à l’étranger

Pour les traitements décrits ici, les prestataires concernés sont GitHub pour l’hébergement du site et Hostpoint pour la messagerie. Les données pertinentes peuvent aussi être communiquées à une autorité lorsqu’une obligation légale l’exige.

GitHub indique traiter des données personnelles notamment aux États-Unis et dans d’autres pays où ses sociétés et prestataires opèrent. GitHub annonce adhérer au Swiss–U.S. Data Privacy Framework et utiliser des clauses contractuelles types pour certains transferts internationaux. Ces informations décrivent les engagements publiés par GitHub. Déclaration de confidentialité de GitHub

Combien de temps conservons-nous vos données ?

Nous conservons les informations liées à une demande aussi longtemps que nécessaire pour y répondre et en assurer le suivi. Si une prestation est convenue, les informations nécessaires à son exécution sont conservées pendant la relation contractuelle et, ensuite, pour satisfaire aux obligations légales applicables ou faire valoir ou défendre des droits. Les données devenues inutiles sont supprimées, sous réserve de ces obligations.

Les journaux techniques et sauvegardes des prestataires suivent leurs propres règles de conservation, selon les finalités techniques et les obligations applicables décrites dans leurs documents de protection des données.

Cookies et services externes

Nous n’intégrons pas d’outil de suivi publicitaire ni de mesure d’audience à ce site. Le site ne dépose pas de cookies de suivi et n’enregistre pas vos réponses au formulaire dans le stockage permanent de votre navigateur.

Les polices, images, sons et vidéos sont servis avec le site, sans chargement de Google Fonts ni lecteur vidéo externe. Votre navigateur peut conserver des fichiers en cache pour accélérer leur affichage ; vous pouvez effacer ce cache dans ses réglages.

Si nous ajoutons des outils de suivi ou des services externes, cette déclaration et les réglages nécessaires seront revus avant leur activation.

Vos droits

Vous pouvez demander des informations sur les données qui vous concernent, leur rectification et, dans les conditions prévues par la loi, leur suppression. Écrivez à ciao@pastamo.ch, ou à l’adresse postale indiquée ci-dessus. Une vérification de votre identité peut être nécessaire pour protéger vos données. Certaines informations doivent être conservées lorsqu’une obligation légale ou un autre motif légal s’y oppose. Vos droits selon le PFPDT
